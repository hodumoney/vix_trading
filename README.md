# VIX 적립 매수 시스템 (자동 수집 + 대시보드)

VIX(공포지수)에 따라 매일 매수금액(1만~10만원)을 계산하는 다기간 DCA 함수를,
GitHub Actions로 매 거래일 데이터 자동 수집·재적합하는 개인용 시스템입니다.

> 2026-11-26: 매일 밤 11시 적립 매수 텔레그램 알림(alert.yml, notify.py)은 종료했습니다.
> 지금 텔레그램 알림은 아래 "빅스 매수법 알림"만 옵니다.
> 예전 알림 코드는 Git 기록(커밋 히스토리)에 남아 있어 필요하면 되살릴 수 있습니다.

- 함수: 다기간(1·2·3·5년) 기대성장 곡선, 상한 앵커 VIX 45
- 매수 기준: 전일 종가 VIX로 계산(곡선과 일치)
- 주문: 사람이 토스에서 직접 (자동주문 없음)

## 파일

| 파일 | 역할 |
|---|---|
| data.json | 곡선 충분통계량 + 기간별 대기버퍼 (저장소가 곧 DB) |
| update.py | 매 거래일 VIX/QLD 종가 수집 -> data.json 갱신 (Stooq->Yahoo 폴백) |
| index.html | GitHub Pages 대시보드 (오늘 금액/곡선/데이터 이력) |
| .github/workflows/daily.yml | 데이터 수집 스케줄 |

## 설치

1) 저장소에 파일 전부 업로드
2) Settings -> Actions -> General -> Workflow permissions = Read and write
3) Settings -> Pages -> Deploy from a branch, main / (root)  (대시보드)
4) Settings -> Secrets and variables -> Actions 에 2개 등록 (VIX 30 알림용):
     TG_TOKEN     BotFather가 준 봇 토큰
     TG_CHAT_ID   내 chat id (@userinfobot으로 확인)
5) Actions -> daily-vix-update -> Run workflow (데이터 한 번 수집)

## 매일 일어나는 일
1. 미국 장 마감 후: update.py가 어제 종가 수집 -> data.json 커밋 -> 곡선 재적합
2. 대시보드(index.html)에서 오늘 적립 금액 확인

## 주의
- Stooq/Yahoo는 무료·비공식 소스라 드물게 실패 가능.
- 봇 토큰은 코드/커밋에 직접 넣지 말고 Secrets에만 두세요.
- 참고용 도구이며, 투자 판단과 결과의 책임은 본인에게 있습니다.

# 빅스 매수법 알림 (VIX 30 돌파 단기매매, 규칙 v2)

호두머니 Q투자법 연구(2000~2026 백테스트)에서 고른 규칙을 텔레그램으로 알려줍니다.
같은 텔레그램 봇(TG_TOKEN, TG_CHAT_ID)을 씁니다. 메시지 제목은 [빅스 매수법]입니다.

## 규칙 (D = VIX가 30을 새로 돌파한 날)
1. 신호: VIX 종가 30 이상, 전날 종가 30 미만
2. 매수: D+1 미국장 시가 (기본 TQQQ)
3. 판단: D+2 종가 기준 (한국시간 D+3 아침에 알림)
   - 이익이면 → D+3 시가 매도
   - 손실이어도 ① VIX가 돌파일보다 낮고 ② QQQ가 52주 최고 종가 대비 −20% 이내면 → 계속 보유
   - 그 밖의 손실 → D+3 시가 매도
4. 계속 보유 중: 매일 VIX 종가가 25 미만이면 다음 거래일 시가 매도, 늦어도 D+18 시가 매도
5. 보유 마지막 날 종가에 VIX가 다시 30을 새로 돌파하면 판단을 2거래일 미룸

## 오는 알림 (모두 한국시간 아침 7:40, 데이터가 늦으면 10:10)
| 알림 | 언제 |
|---|---|
| 🚨 매수 신호 | 돌파한 날 다음 아침 (예: 금요일 돌파 → 토요일 아침) |
| ⏰ 오늘 밤 매수 | 신호와 매수일 날짜가 다를 때, 매수일 아침 |
| 🔔 오늘 밤 매도 (이익/손실) | D+3 아침, 연장하지 않을 때 |
| ↪️ 보유 연장 | D+3 아침, 손실이지만 연장 조건이 맞을 때 (조건별 ✅/❌ 표시) |
| ⏳ 계속 보유 | 연장 중 매일 아침 (VIX가 아직 25 이상) |
| 🔔 매도 (공포 진정/기한) | 연장 중 VIX 종가 25 미만이 된 다음 아침, 또는 기한 전날 아침 |
| 🔔 오늘 밤 매도 | 매도일이 주말을 낀 경우 매도일 아침에 한 번 더 |
| ⚠️ 판단 보류 | 10:10까지 가격 데이터를 못 받았을 때 (직접 확인할 기준 안내) |

손익은 매수일 시가 대비(매수 수수료 0.15% 포함)이며, 연장 판단에는 ETF와 QQQ 가격(Yahoo → Stooq)을 씁니다.

## 파일
| 파일 | 역할 |
|---|---|
| signal30.py | VIX·ETF·QQQ 가격 수집 + 규칙 판단 + 텔레그램 발송 |
| signal30_state.json | 이미 보낸 알림 기록(중복 방지). Actions가 자동 커밋 |
| .github/workflows/vix30-alert.yml | 매일 한국시간 07:40 실행, 10:10 재확인 |
| report.py | 데이터 쌓기 + 거래가 끝날 때마다 점검 보고 |
| history/qqq_vix.csv | 2000년부터 QQQ 시가·종가, VIX 종가 (매일 자동 추가) |
| report_state.json | 마지막으로 보고한 거래 기록 |
| .github/workflows/vix30-report.yml | 매일 한국시간 08:00 실행 |

## 점검 보고 (report.py)
매일 한국시간 08:00에 새 QQQ·VIX 종가를 `history/qqq_vix.csv`(2000년부터)에 쌓습니다.
실전 거래(2026-11-20 신호 이후)가 하나 끝나면 다음 날 아침 텔레그램으로 보고서가 옵니다.

- 누적 백테스트 성과 (TQQQ·QLD, 쉬는 돈 단기채, 앞 2000–12 / 뒤 2013~ 기간)
- 실전 기록: 규칙대로 했다면의 거래별 결과
- 기준값 점검: 돌파 VIX(28~32) / 연장 중 매도 VIX(21~29) / 약세장 기준(−10~−30%) / 기한(D+8~D+28)을 하나씩 바꿨을 때 연 수익
- 판정: 아래 조건을 모두 넘는 값이 있으면 "⚠️ 검토 필요", 없으면 "✅ 유지". 기준값은 자동으로 바꾸지 않습니다.
  - 연 수익이 지금보다 1%p 이상 높음
  - 앞 기간(2000–12)과 뒤 기간(2013~) 모두 지금보다 높음
  - 바로 옆 값도 지금보다 높음 (한 점에서만 좋은 값 제외)
  - 최대낙폭이 지금보다 3%p 넘게 나빠지지 않음

지금 바로 받아 보기: Actions → vix30-report → Run workflow → mode = report

TQQQ·QLD는 QQQ로 합성해 계산하므로 실제 체결과 조금 다를 수 있습니다.
report.py의 RF_YEAR(연방기금금리 연평균)는 해마다 한 번 고쳐 주세요(없는 해는 마지막 값 사용).

## 테스트
Actions → vix30-alert → Run workflow → mode = status → 지금 상태가 텔레그램으로 옵니다.

## 바꾸고 싶을 때

- 휴장일: signal30.py 위쪽 HOLIDAYS에 해마다 NYSE 휴장일 추가 (현재 2025~2028 입력됨)

## 주의
- 판단은 VIX·가격 종가 기준이라 장중 값과 다를 수 있습니다.
- 손익은 매수일 시가 기준이라 실제 체결가와 조금 다를 수 있습니다.
- 주문은 사람이 토스에서 직접 합니다(자동주문 없음).
- 과거 백테스트 결과는 미래를 보장하지 않습니다. 참고용 도구입니다.
